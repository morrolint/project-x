# Agent 技能库

> 自动化会话（早报/晚间/收件箱处理）在此查找"怎么做"的方法文档。
> 技能只写**方法**（步骤化、可复述），**不写可执行代码**——需要代码的走
> `../integrations/proposals/` 提案（见 integrations/README.md 的 skill 契约）。

## 文件格式

```
skills/<skill-name>/SKILL.md
---
name: <kebab-case 名>
description: 一句话说明何时用
---
## 方法
（步骤）
## 来源
（提炼自哪个项目/哪次讨论，附日期）
```
