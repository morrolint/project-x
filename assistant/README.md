# 个人助手 · 指挥部

ZCode 作为常驻个人助手的运行基地。所有文件都在你本地，不上传任何服务器。

## 目录结构

```
assistant/
├── README.md   ← 本手册
├── TASKS.md    ← 任务收件箱：想让我"离线时"干的活，写在这里
├── reports/    ← 产出归档：每日早报、各类汇报（按日期命名）
└── docs/       ← 个人文件库：证件、归档文件、想让我随时能取的资料
```

## 怎么用

- **平时**：直接在会话里说话即可，我有持久记忆，记得你是谁、在做什么。
- **不在电脑前**：把任务写进 `TASKS.md`（一行一条，写清楚"要什么"就行）。每天早上的自动化会处理收件箱并把结果并进早报。
- **要文件**：把文件扔进 `docs/`（支持文本、PDF、图片——我能直接看图），然后说"把我的 XX 发我"或"找一下 XX"。
- **早报**：每天 08:00 自动生成到 `reports/`，内容=热点新闻 + GitHub Trending + AI 摘要 + 收件箱处理结果。骨架由脚本生成，自动化再补充科技动态和点评。

## 报告脚本（v0）

`scripts/report.py`——确定性生成报告骨架，任一数据源失败自动跳过并在报告末尾注明：

```bash
python3 assistant/scripts/report.py morning   # 早报（要闻+Trending+热搜+收件箱）
python3 assistant/scripts/report.py evening   # 晚间简报（热搜晚间榜+Trending 对比+收件箱巡检）
# 可选：--date YYYY-MM-DD  --output-dir DIR  --force（覆盖已存在的报告）
```

数据源：每天60秒读懂世界（blog.intelexe.cn）/ GitHub Trending / 微博热搜官方接口。GitHub 直连超时会自动走本机代理 127.0.0.1:7892（环境变量 `ASSISTANT_PROXY=off` 可禁用）。

## 已注册的自动化

| 名称 | 时间 | 内容 |
|---|---|---|
| 两班倒·早报+晚间简报 | 每天 08:00 / 21:00 | 08:00 跑 `report.py morning` 生成早报 → 补科技动态、写点评 → 处理 TASKS.md 收件箱；21:00 跑 `report.py evening` 生成简报（与早报对比 Trending）→ 巡检收件箱 |

在 ZCode 的 Automations 页面可以暂停/修改；或者直接跟我说"停掉早报/改到 9 点"。

## 能力边界（诚实版）

- ✅ 联网搜索与抓取、读写本地文件、看图、定时任务、长期记忆
- ⚠️ 只在你 Mac 开机时工作——睡眠/关机期间离线
- ❌ 不能主动收微信/邮件消息（无入站通道；需要时可讨论自建桥接）
- ❌ 不能替你操作系统级权限以外的事（不会乱装软件、不动系统配置）

## 隐私边界

`docs/` 里的敏感文件（如证件）只在你主动让我读取时才会进入对话上下文；日常早报流程不扫描这个目录。
