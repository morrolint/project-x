## 深读四则

**GenericAgent——经验固化（最直接的吸收源）**：哲学"**不预设技能，靠进化获得能力**"。每解决一个新任务，自动把执行路径固化为可复用 Skill，越用技能树越大；自举实证（仓库全部由 agent 自己提交）。**这正是 Project X 缺的半环**：我们的技能目前只从"外部发现"（早班 Trending→skills）生长，不从"自身经验"生长。

**Raven——变更过门**：RSI 的核心不是"改自己"，是"**提议修改自己的 harness → 评估 → 通过验证才采纳**"的闭环。内置 Raven-Research/Code/Design/Oncall 四 agent。太重不装，但 propose→evaluate→adopt + 验证门是自进化的安全阀——与用户刚立的多参照系协议天然同构。

**evolver——可审计进化 + 产权教训**：GEP 驱动、全程可审计；因遭同赛道项目无署名抄袭而转 source-available。教训：自进化的每一步变更必须留审计痕迹（我们有 git + ADR + registry provenance——已是对的做法，需坚持）；吸收外部进化资产时注意许可（GPL/AGPL 不混入 MIT 侧代码）。

**CowAgent——大它我**：与 Project X 定位几乎重合（个人助手、技能、记忆、IM 多平台、7×24 本机）但体量 47k★。**定为对照基准**：它的能力清单是我们"缺什么"的免费坐标系，不必安装。

## 对 Project X 的映射：自进化闭环 v1（三件套）

1. **经验固化**（GenericAgent 思想）：非平凡任务完成 → daemon 反思"这是可复用模式吗" → 固化 skill（过 agent-discipline 纪律 + PM 交付标准）
2. **变更过门**（Raven 思想）：agent 对自身的修改（提示/技能/gate_rules）一律走 propose→test→registry 校验→（风险级）用户确认——测试套件是进化 的验证器
3. **进化日志**（evolver 思想）：每次自进化落 git commit + registry provenance；能力对 CowAgent 基准定期对照

安全边界（宪法不变量延续）：进化不得触碰 docs/ 与密钥；不得私自安装（四铁律）；高风险自改必须人工确认。
