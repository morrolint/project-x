# ADR-003 · 确认门与分级策略数据化

- 状态：已接受（2026-10-14）
- 背景：重大/不可逆操作必须用户确认（NeedsConfirmation）；但班次自治（无人值守写报告）
  与"每次都打字确认"冲突；曾因重启丢挂起态、消息重复投递。
- 决策：
  1. 确认挂起态落盘 tasks/<id>.json（WAITING_USER 为一等状态），重启可恢复、僵尸收尾提示重试；
  2. 分级策略数据化于 agent/gate_rules.json：chat 窄口径（reports/）与 wide 班次口径
     （另含 skills/proposals/registry/TASKS/memory）；docs/ 与密钥任何口径永拦（写死在机制）。
- 后果：机器产物区直行、班次自治、红线不可豁免；改策略只动 JSON 不动代码。
