# ADR-002 · 集成一律走 registry 插件管线

- 状态：已接受（2026-10-09 起）
- 背景：早期"来一个加一个"式打补丁不可持续；AI 助手天然持续暴露于新工具诱惑。
- 决策：四铁律——registry.json 唯一事实源 / 宿主脚本不认识具体源 / 禁止私自安装 /
  失效即退役。六种类型（report-source / push-channel / channel-inbound / skill /
  persona / ui-kit / capability）全部"目录即插件 + registry 条目"，check_registry.py 机器校验。
- 后果：新增集成零改宿主；代价是新类型需先扩展契约表与校验器（一次成本）。
- 提案流：装代码/服务/凭据的集成必须经 proposals/ 提案 + 用户"批准 <id>"。
