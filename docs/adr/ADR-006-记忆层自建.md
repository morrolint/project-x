# ADR-006 · 记忆层自建（markdown+BM25），不引入 hindsight 服务

- 状态：已接受（2026-10-14，v0.2 落地）
- 背景：hindsight（月榜 #2，49k★）提供四类记忆/四路检索/observations 固化/mental model 等成熟设计，
  但自托管栈重（docker+向量库+reranker）；agentmemory 基准显示 BM25 单路即可 86%+。
- 决策：吸收设计不装服务——BM25 + facts/月度双层 + Memory Defense 打码 + profile.md 常备页
  （纯 stdlib）；observations 后台固化为第二批后段；向量/图谱路仅在触发器（见 ARCHITECTURE.md）出现时重审。
- 后果：召回上限低于向量融合，但零依赖零运维，且升级路径（换 recall 实现）不动调用方。
