# ADR-004 · ZCode 自动化层退役，班次由 daemon 内置调度器接管

- 状态：已接受（2026-10-14 决策；待删自动化后完全生效）
- 背景：ZCode 自动化层 8 次触发、8 次零产出（三台机器同症状），判定不可靠；
  每班人肉补跑成本约 1 小时/天。
- 决策：早晚班由 daemon 内置调度器接管（scheduler.py，08:00/21:00，state.json 当天去重，
  --shift 手动触发同流程）；ZCode cron 停用。
- 后果：班次输出与 daemon 共用任务线/进度面板/确认门分级，报告写入免确认直行；
  单点收敛到 daemon 进程本身（launchd KeepAlive 兜底）。
