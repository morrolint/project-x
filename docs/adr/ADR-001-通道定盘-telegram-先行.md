# ADR-001 · 入站通道定盘：Telegram 先行

- 状态：已接受（2026-10-10 定盘；原决策 2026-10-07 为飞书优先）
- 背景：推送链路 Telegram 已验证且用户日常在用；飞书可国内直连但当时未开通。
- 决策：Telegram 先行（入站+出站），飞书作为预留通道（channels/ 插件同接口，不排期）。
- 后果：收发全程依赖本机代理（因机而异，ASSISTANT_PROXY 覆盖）；VPN 断 = 通道断，
  断联消息由 Telegram 服务端保留、恢复补收。换取：零开通成本、既有 bot 与白名单资产。
- 2026-10-10 追加：用户确认"通道各归各"——Dots/其他 agent 永不经 Telegram 桥接。
